# Agent Instructions

The README file is autogenerated from the main module. To update documentation:

1. Edit the main module source file
1. Run `perl Build.PL && ./Build distmeta` to regenerate the README

## Search verification

For changes to search indexing or API response contracts, run the live tests
as a required validation step:

```sh
TEST_WITH_OPENSEARCH=1 prove -l t/61_meon-Web-Index.t t/62_meon-Web-SearchAPI.t
```

Configure `OPENSEARCH_TEST_HOST` and optional `OPENSEARCH_TEST_BASIC_AUTH` for
an isolated test backend. These tests recreate the `meon-search_search_t_*`
indices. A default run without `TEST_WITH_OPENSEARCH=1` skips this coverage.
